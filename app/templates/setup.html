Build it yourself in Shortcuts

Do not use Request Body: Form. Form fields are text. Recorded Audio is a file, so the variable picker will not offer it there. Use Request Body: File instead.

  1. Open Shortcuts. Tap +. Name it Voice Dump.
  2. Add Record Audio. Start Recording: Immediately. Finish Recording: On Tap. Do not save to Photos.
  3. Add Get Contents of URL.
    • URL = the Ingest URL from this page.
    • Method POST.
    • Headers: add Authorization with value Bearer then insert your Token variable (or paste Bearer vnp_…).
    • Request Body: File (not Form, not JSON).
    • File = Recorded Audio. That picker accepts the recording.
  4. Get Dictionary Value key title, Get Dictionary Value key status, Show Notification from those.
  5. Settings, Action Button, that shortcut.

Use Shortcuts Import Questions for Ingest URL and Token so those values are filled on install. A second optional shortcut, Process Voice Memo, can receive Audio from the Share Sheet and POST the same way with File = Shortcut Input.

Troubleshoot

  • 401 — bad or stale token. Copy the token on this page and update it in the shortcut.
  • 413 — recording is too big. Talk shorter, or raise MAX_UPLOAD_MB.
  • error status on a note — open it and tap Retry. Audio and transcript are kept.
