Build it yourself in Shortcuts
  1. Open Shortcuts. Tap +. Name it Voice Dump.
  2. Add Record Audio. Stop Recording: On Tap. Do not save to Photos.
  3. Add Get Contents of URL. URL = ingest URL. Method POST. Body Form. file = Recorded Audio. token = their token. source = ios-shortcut.
  4. Show Notification from the JSON title and status.
  5. Settings, Action Button, that shortcut.

Use Shortcuts Import Questions for Ingest URL and Token so those values are filled on install. A second optional shortcut, Process Voice Memo, can receive Audio from the Share Sheet and POST the same way with file = Shortcut Input.

Troubleshoot

  • 401 — bad or stale token. Copy the token on this page and update it in the shortcut.
  • 413 — recording is too big. Talk shorter, or raise MAX_UPLOAD_MB.
  • error status on a note — open it and tap Retry. Audio and transcript are kept.
